# FaroSwap GSP Price Manager module

Independent module implementing the approved FaroSwap public Pegged/GSP pool delivery:
an upgradeable Price Manager that is the pool `admin` and synchronizes the anchor price `i`
to the fixed stPROS redemption rate, plus a one-shot atomic 0.01-stPROS bootstrap. The frozen
stPROS V4 core, its protected artifacts and the SLP module are untouched; this module adds no
new vendored dependency (byte-exact copies of the root vendor closure under `lib/`/`test-lib/`,
recorded in `DEPENDENCIES.json`, regenerated by `tools/vendor_closure.py`).

- `contracts/FaroSwapPriceManager.sol` — UUPS-style manager (ERC-1967 proxy from the frozen
  OZ closure): executor-gated `syncPrice()` (fixed source `stPROS.convertToAssets(1e18)`,
  clean no-op on equal price), Safe-only `setPriceLimit`, Safe-only one-time `bindPool` with
  full provenance validation, two-step ownership, Safe-only upgrades.
- `contracts/FaroSwapPoolBootstrap.sol` — atomic first LP mint to the governance Safe.
- `tests/` — 69 unit/security tests over a faithful GSP-semantics mock topology (UUPS call-context
  matrix, forward/rollback upgrade chains, pre-binding safety incl. the adjustPrice-exact
  deviation denominator), plus 12 deterministic Python regressions for the deployment plan
  (nonce sequence, address derivation).
- `fork-tests/` — 11 mainnet-fork rehearsal tests against the real factory/template/vault/oracle,
  pinned to reproducible block 22921747 (including bind-time price-deviation and seeded-pool
  rejection on real bytecode).
- `docs/` — DESIGN.md (architecture/threat model), PARAMS.md (frozen parameters + evidence),
  DEPLOYMENT.md (runbook).
- `deployments/pharos_pacific_mainnet/prepared/` — regenerated, unsigned deployment plan.

## Run the gates (only inside the approved export)

```sh
make faroswap-test   # unit + security suite (offline)
make faroswap-fork   # mainnet fork rehearsal via the public read-only RPC
python3 faroswap/scripts/prepare_deployment.py   # regenerate the deployment plan (read-only)
```
